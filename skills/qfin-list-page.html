中后台列表页生成

Admin list page generator

BitPan666 / qfin-list-page

把业务需求转成标准桌面端列表页。一个统一入口，按目标平台调用专属规范，支持在 Figma 中创建、更新和检查页面。

一套入口，三套平台规范

日常只需调用 $qfin-list-page。它会根据你指定的平台，选择毓数、金毓盟或电销的一个专属 Skill，并把完整业务需求交给对应平台处理。

创建列表页

从导航、筛选项、表格列和操作要求开始，生成标准页面。

从安装到第一次生成

  1. 安装 QFIN List Page，连接 Figma

    使用安装区的对话提示词，或在已安装 Codex CLI 的终端执行安装命令。随后安装并授权 Figma 插件，新建任务，通过 @ 选择 Figma 与 QFIN List Page。

  2. 提供平台和业务需求

    选择一个目标平台，补充文件、Page、导航、筛选和表格字段。布局与组件规则交给对应平台 Skill。

  3. 生成后核对结果

    检查选中的平台、目标位置、业务字段与验收结果。更新页面时，明确要保留和调整的内容。
